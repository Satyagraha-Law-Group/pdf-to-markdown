# Process workflow — lawyer + agent (post-GODI)

**Stamp:** `SLG-Process-Workflow-v-1-0-19-09-2026-18-35-03.md`

1. Drop PDFs in `0_01_RAW_PDF` (or point Spock at a TO-DO intake list).
2. Spock asks **Local Tesseract vs Mistral**.
3. Convert → report fidelity + paths.
4. If Empty PDF / low fidelity: Spock proposes raster (`_raster`) and/or Gemini hybrid; waits for your call when consequential.
5. You review markdown; say **Lint** / **Approved.** as needed.
6. Spock closes GUBERNATIO, moves PDFs, stages copies if you named a TO-DO folder.
7. Optional: Spock emits GUBERNATIO convert report (MD+HTML) for the window.
8. Layer 1 ends. Matter/editing/site work is a separate ask.

See also: `SLG-Convert-Learnings-v-1-0-19-09-2026-18-35-03.md`, `SLG-Ops-Playbook-v-1-0-19-09-2026-18-35-03.md`.
