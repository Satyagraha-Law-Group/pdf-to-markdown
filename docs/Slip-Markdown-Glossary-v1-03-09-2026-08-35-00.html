Slip Markdown Glossary

GUBERNATIO

GUBERNATIO is the proper Latin noun meaning the system of governance, steering, direction, and administration.

In this product it is a SQLite table named GUBERNATIO inside the Document-Hash-Registry. GUBERNATIO is the entry gate. After SHA-256, convert asks whether this hash is already DONE. If yes, park the duplicate and update the identity registry second. documents stays one row per SHA-256.

Mistral key lease

The same Mistral API key must not be dual-used. Local Tesseract takes no lease. GUBERNATIO stores a SHA-256 fingerprint of the key, never the key. The sentinel is a zero-byte file next to the sqlite named exactly SLG-pdf_to_md_file_naming_convention.text. Default lease is 15 minutes; an expired RUNNING lease is free so the next lawyer is not stuck. A held unexpired lease returns HALT and does not move RAW.

slip-pdf-md registry gubernatio --vault "PATH/TO/SLIP_DOCUMENT_PROCESSING"
