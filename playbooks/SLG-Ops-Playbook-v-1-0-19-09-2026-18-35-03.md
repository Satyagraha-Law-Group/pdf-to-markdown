# Playbook — Empty PDF / low fidelity / raster / Gemini / approve / quarantine

**Stamp:** `SLG-Ops-Playbook-v-1-0-19-09-2026-18-35-03.md`  
**Master learnings:** `SLG-Convert-Learnings-v-1-0-19-09-2026-18-35-03.md`

## A. Empty PDF after Mistral
1. Confirm PDF opens; `pymupdf` page_count and `get_text()` sample.
2. Rasterize all pages ~220 dpi → `Name_raster.pdf` (underscore, not `.raster.`).
3. Convert `--engine mistral --force --input <Name_raster.pdf>`.
4. Canonicalize markdown; note raster method in front matter.
5. Eye-compare vs any prior native Mistral draft; **keep the better one**.

## B. Low fidelity / NEEDS_REVIEW after good-looking Mistral
1. Read fidelity report — compare to Tesseract-overlap meaning.
2. Ask Anil: approve override · Gemini · dual-file · tool-gate change.
3. Do not burn identical native Mistral `--force` hoping for 0.90.

## C. Raster scored worse than native
1. Keep native CLEAN / APPROVED draft.
2. Quarantine raster PDF/MD/false-pass Tesseract outputs under `99_98_QUARANTINE\YYYY-MM-DD_*`.
3. README with delete-by time; calendar 15-min review; escalate if overdue.

## D. Gemini path (long scan)
1. Approve load of `GEMINI_API_KEY` (Point-and-Load); verify non-empty length.
2. Probe working model (`gemini-3.1-flash-lite` worked 18 Sep 2026).
3. Page images ~200 dpi; batch 1; backoff on 503.
4. On RECITATION pages → Tesseract fill; restitch; document hybrid.

## E. Approve close-out
1. Lint PROJECT-NAME / CLIENT / obvious OCR typos.
2. CLI approve for the document.
3. Ensure CLEAN FM `processing_status: APPROVED`.
4. Sync GUBERNATIO/documents for **every SHA** (original + raster if any).
5. PDFs → `60_90_PROCESSED`.
6. No invented Layer-2 briefs.

## F. Batch GUBERNATIO convert report
1. Query registry for window (e.g. 18–19 Sep).
2. One row per SHA-256; highest lifecycle status.
3. Emit MD + HTML under `90_00_PROJECT_TOOLING\pdf-to-markdown\logs\` with SLG stamp + LATEST pointers.
4. Optional: stage copies into operator TO-DO `PROCESSED_PDF` / `APPROVED_MARKDOWN`.

## G. PowerShell convert one-liner pattern
```powershell
$env:MISTRAL_API_KEY = (Get-Content .\SECRETS.txt | Where-Object { $_ -match '^MISTRAL_API_KEY=' }) -replace '^MISTRAL_API_KEY=',''
# never Write-Host the key
'' | python -m slip_pdf_md convert --engine mistral --input $pdf 1> convert.out.log 2> convert.err.log
```
